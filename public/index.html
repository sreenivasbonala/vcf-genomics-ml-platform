📝 Professor's Whiteboard SQL Query Tasks

Interactive execution of the 2 queries written on the classroom whiteboard

Live SQL Engine

1. Filter Genome Build & Position (Genotype = 1/1)

SELECT gl.genome_build, gl.position
FROM genomic_loci gl
JOIN variant_calls vc ON gl.locus_id = vc.locus_id
WHERE vc.genotype = '1/1';

2. Update Reference & Alternate Alleles to 'G' and 'A'

UPDATE genomic_loci
SET reference_allele = 'G', alternate_allele = 'A'
WHERE locus_id IN (
  SELECT locus_id FROM variant_calls
  WHERE filter_status = 'PASS' AND allele_frequency = 0.08
);
