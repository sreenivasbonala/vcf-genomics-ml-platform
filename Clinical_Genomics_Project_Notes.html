1. Project Overview & Core Goals

In modern genomics, Next-Generation Sequencing (NGS) machines sequence patient DNA and output variants (mutations) in Variant Call Format (VCF) files. This enterprise platform solves 5 core challenges:

  • Secure Authentication: Password hashing using scrypt, 1-Hour short-lived Bearer tokens, and Role-Based Access Control (RBAC).
  • Object Storage & Deduplication: Large VCF files are saved to object storage while metadata is indexed in a relational DB; identical files are detected via SHA-256 to prevent duplicate disk storage.
  • Bioinformatics Quality Control: Automatically calculates the Transition/Transversion (Ti/Tv) Ratio (human benchmark ≈ 2.12).
  • PostgreSQL Relational Schema: Normalizes variants into 13+ relational tables matching \dt standards with strict ON DELETE CASCADE.
  • Precision Oncology Integration: Connects to the CIViC database for FDA-approved targeted cancer therapies.

3. Security & Password Hashing (scrypt)

Raw passwords are never stored. The platform implements the memory-hard scrypt algorithm demonstrated in the classroom:

// scrypt Output Format:
scrypt$<N>$<r>$<p>$<salt_hex>$<digest_hex>

// Example stored in users.password_hash:
scrypt$16384$8$1$0cacdf361c3a5df9...$047cca41b59da035...
  • Salt (16 random bytes): Guarantees unique hashes even if two users choose the same password. Thwarts Rainbow Table attacks.
  • N = 16384 (CPU/Memory Cost): Forces high RAM consumption per attempt, making GPU/ASIC brute-forcing computationally unfeasible.
  • r = 8 (Block Size), p = 1 (Parallelization), dklen = 64 (Key Length).
  • Session Model: Bearer Token with a strict 1-Hour Time-to-Live (TTL).

4. Object Storage & SHA-256 Deduplication

Storing 100 MB VCF files directly inside a database causes significant bloat and latency. Our solution:

  • Object Storage: Raw VCF file is written to /uploads/ on disk.
  • Relational DB: File metadata is saved in the uploads table.
  • Deduplication: The server computes the SHA-256 hash. If SELECT * FROM uploads WHERE sha256 = ? finds a match, the duplicate file on disk is deleted immediately, and the existing record is returned.

6. Classroom Whiteboard SQL Queries

Task 1: Filter Genome Build & Position for Genotype = '1/1'

SELECT gl.genome_build, gl.position
FROM genomic_loci gl
JOIN variant_calls vc ON gl.locus_id = vc.locus_id
WHERE vc.genotype = '1/1';

-- Output:
-- 1. GRCh38 | 100037 (Chromosome 2)
-- 2. GRCh38 | 100111 (Chromosome 17)

Task 2: Conditional Allele Mutation Update

UPDATE genomic_loci
SET reference_allele = 'G', alternate_allele = 'A'
WHERE locus_id IN (
  SELECT locus_id FROM variant_calls
  WHERE filter_status = 'PASS' AND allele_frequency = 0.08
);
-- Output: Updates Locus 3 (TP53 locus) to G > A

7. Quality Control & Clinical Integrations

  • Ti/Tv Ratio = 2.12: Whole-genome sequencing benchmark. Transitions ($A \leftrightarrow G, C \leftrightarrow T$) occur more frequently than transversions. A ratio below 2.0 flags low quality data.
  • CIViC Cancer Drugs: Cross-references mutations with clinical trials (e.g. BRAF V600E → Vemurafenib; EGFR L858R → Osimertinib).
